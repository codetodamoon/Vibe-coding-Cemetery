# Crypto-Trading-Bot

## 愿景
让 AI 分析链上数据，自动发现 DeFi 套利机会并执行交易，实现被动收入。

## 技术栈
Python + Web3.py + ChatGPT API + Uniswap SDK

## 死亡笔记
AI 信誓旦旦告诉我"这个 ERC-20 代币的 `totalSupply()` 函数返回值经过数学验证，100% 安全"。实际上这个代币有个 `mint()` 函数，任何人可以无限铸造。AI 援引的"数学验证"来自一篇 Medium 博客，该博客由项目方自己写。debug 三天无果，Gas 费烧了 0.3 ETH。

## 墓志铭
AI 的自信来自训练数据，不是现实。
