# AI-Outfit-Planner

## 愿景
上传衣橱照片，AI 根据天气、日程和个人风格，每天早上推荐穿搭。

## 技术栈
React + TensorFlow.js + OpenWeather API

## 死亡笔记
产品完美运行，算法精准，推荐逻辑自洽，内测反馈"很好用"。上线后 DAU 0。真正的问题：穿什么衣服这件事，用户在 30 秒内自己就决定了，根本不需要 AI 来告诉他们。这个 app 解决的不是问题，是一个用户并不存在的问题。

## 墓志铭
有些问题，最好的解决方案是"别管它"。
