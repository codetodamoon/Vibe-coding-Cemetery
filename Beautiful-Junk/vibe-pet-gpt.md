# Vibe-Pet-GPT

## 愿景
做一个能跟猫说话的 AI，分析猫的表情和叫声，告诉主人猫在想什么。

## 技术栈
React Native + Whisper API + GPT-4 Vision

## 死亡笔记
录音了 1000 次，只有 3 次识别出了猫叫。剩下的全是"检测到环境噪音：主人吸猫"。产品逻辑完美——但猫不看屏幕。测试那天，主角（猫）全程在纸盒子里睡觉，任何对话请求都被回以一个白眼和一声"喵"。

## 墓志铭
最大的产品发现：目标用户不关心产品。
