# AI-Weekly-Digest

## 愿景
每周自动抓取 50 个 Newsletter，AI 总结成一份精炼的 5 分钟早报，发到邮箱。

## 技术栈
Python + Feedparser + Claude API + Mailgun

## 死亡笔记
做完了，上线了，用了一周，然后取消了订阅。因为你自己看 Newsletter 也就 10 分钟，这个产品帮你"节省"了时间但同时让你失去了 context——你不知道哪些内容来自哪个 Newsletter、该不该 follow 某个作者。产品做完了，发现你并不需要它。

## 墓志铭
效率工具的终点，是让你更慢地做你真正想做的事。
