# Vibe-CTO-Assistant

## 愿景
做一个 AI CTO，你描述业务需求，它输出系统架构、Docker 配置和 CI/CD 流水线。

## 技术栈
LangChain + GPT-4 + Draw.io API

## 死亡笔记
输出了 300 行 YAML，每一行都语法正确，每一行都不知道在干嘛。架构图很漂亮，但跟我要做的社交 app 完全没关系。问了三个 senior 工程师，都说"这个架构能跑，但你不需要它"。最后花了两天手工重写。

## 墓志铭
AI 给的架构像一件高定西装——尺寸完美，但你是个程序员。
