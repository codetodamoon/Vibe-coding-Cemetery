# Auto-Blogger-GPT

## 愿景
用自然语言告诉 AI "帮我写一个每天自动抓取 Hacker News 并生成中文摘要的博客机器人"，然后躺平等它自己跑起来。

## 技术栈
Next.js + Claude API + Vercel Cron + Supabase

## 死亡笔记
Prompt 写了三版，每一版都说"好的，我已经理解了你的需求"。实际情况：第二天醒来，数据库是空的，邮箱收到了 47 封错误日志。"AI 自动化" 最后变成"AI 自动制造焦虑"。最后手动跑了一次，发现它确实能跑，但需要 14 个步骤配置 API key。

## 墓志铭
从"躺平"到"躺不平"，只差一个 README 的距离。
